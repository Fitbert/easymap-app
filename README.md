# easymap-app

Maps for seniors.

## Status

Just started — the repo currently only has an MIT license and no code yet. This README is a placeholder to fill in as the project takes shape.

## Idea

A simplified maps app aimed at older users: larger text and touch targets, fewer options on screen, and a more forgiving interface than mainstream map apps.
